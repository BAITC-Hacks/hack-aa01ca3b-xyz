# HackAlem AI — local meeting minutes and action tracking

Hackathon team repository for XYZ. Прототип принимает аудио- или видеозапись совещания, строит транскрипт на русском, казахском и смешанном языке, определяет смену говорящих, извлекает поручения и формирует краткое саммари. Результат можно проверить и отредактировать в браузере, затем скачать в DOCX или PDF.

## Возможности

- Локальная транскрибация с автоматическим определением языка через faster-whisper
- Локальная диаризация через pyannote Community-1 с привязкой временных фрагментов к меткам спикеров.
- Извлечение поручений и саммари локальной LLM через Ollama. Если Ollama не запущен, доступен упрощённый эвристический режим; поручения в нём нужно проверить вручную.
- Редактирование поручения, ответственного, спикера, срока и статуса; панель просроченных и ближайших сроков.
- Экспорт полного протокола и транскрипта в DOCX и PDF.
- Временное хранение исходной записи: после обработки она удаляется. Модели хранятся в локальной папке `models/`.

Диаризация определяет голоса как `SPEAKER_01`, `SPEAKER_02` и т. д., но не устанавливает личности. Сопоставьте метки с именами вручную перед экспортом. Если в речи нет точной даты поручения, автоматическое напоминание по календарю не создаётся.

## Требования

- Python 3.10 или новее.
- Ollama с локальной моделью `qwen2.5:3b` для семантического извлечения поручений и саммари.
- `ffmpeg` в `PATH` для загрузки видео; аудиофайлы можно загружать без установленного ffmpeg.
- Hugging Face token для однократной загрузки pyannote Community-1. Перед загрузкой примите условия использования модели на Hugging Face.

## Запуск на Windows

Из корня репозитория в PowerShell:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Установите Ollama и скачайте локальную языковую модель:

```powershell
ollama pull qwen2.5:3b
```

В PowerShell задайте Hugging Face token и один раз загрузите модели распознавания. Запись и транскрипт при этом не загружаются — скачиваются только веса моделей:

```powershell
$env:HF_TOKEN = "ваш_huggingface_token"
python scripts\download_models.py
```

После установки моделей приложение использует только закэшированные файлы:

```powershell
streamlit run app.py --server.address 127.0.0.1 --server.port 8501
```

Откройте `http://127.0.0.1:8501`. Приложение слушает только loopback-интерфейс. Ollama URL по умолчанию — `http://127.0.0.1:11434`; приложение отклоняет удалённые адреса, чтобы не отправлять транскрипт во внешнюю службу.

Для обработки видео установите ffmpeg и убедитесь, что команда `ffmpeg -version` работает.

## Сценарий демонстрации

1. Загрузите согласованную тестовую запись на русском, казахском или смешанном языке.
2. Укажите название и дату, подтвердите уведомление участников о записи.
3. Нажмите «Создать протокол» и проверьте язык, спикеров, саммари и список поручений.
4. При необходимости сопоставьте метки спикеров с участниками и исправьте ответственных, сроки или статусы.
5. Скачайте DOCX или PDF.

Реальные записи для демонстрации должны быть обезличены. Не загружайте запись без согласия участников.

## Конфиденциальность и развёртывание

Во время обработки faster-whisper и pyannote работают локально. Ollama вызывается только через loopback. Внешние API распознавания или анализа не используются; сетевой доступ требуется только для первоначальной установки пакетов и скачивания весов. Pyannote телеметрия отключена, загрузка Hugging Face телеметрии также выключена. Для закрытого контура заранее поместите веса моделей в `models/` и установите пакеты в изолированном окружении, затем заблокируйте исходящий сетевой трафик.

Прототип не подключается к Teams, Zoom или Google Meet и не отправляет push/email-напоминания. Напоминания о просроченных или наступающих сроках показываются в панели при просмотре сформированного протокола.

## Статический макет панели задач

Для отдельного демо интерфейса контроля сроков откройте `index.html` в современном браузере. Сборка и установка пакетов не нужны. Задачи и отметки выполнения сохраняются локально в браузере; тестовые данные вымышленные.
