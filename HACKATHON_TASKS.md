# Задачи команды хакатона

Актуальная карта требований кейса, распределения работ между тремя участниками, статусов и оставшихся шагов поддерживается в [`CASE_TASK_MAP.md`](CASE_TASK_MAP.md). Обновляйте её, чтобы не расходились два списка задач.

Примеры совещаний и поручений из материалов организаторов находятся в `samples/organizer_examples/`; это тестовые данные для проверки инструкций и результата LLM, а не список дел команды и не набор для дообучения весов модели.
