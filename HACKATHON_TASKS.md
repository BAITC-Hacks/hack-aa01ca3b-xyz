# Трек 08 «Инновации»: задачи команды

## Задача

Система автопротоколирования совещаний с фиксацией поручений: запись совещания на русском, казахском
или шала-казахском → транскрипт с разделением говорящих → поручения (кто, что, срок) → саммари →
протокол DOCX/PDF. Ограничение ТЗ: без внешних облачных API, только локальные модели.

## Распределение работы

| Участник | Зона ответственности | Результат для демо |
|---|---|---|
| Бэкенд | Приложение Streamlit, обработка записи, экспорт, запуск по README | Загрузили запись → получили протокол |
| Промпты и ИИ | Промпты ИИ-агента, проверка на примерах из ТЗ, README | Поручения совпадают с эталонными таблицами организаторов |
| Дизайн | Интерфейс, тестовая запись совещания, презентация | Понятный экран и живая запись на ru/kk/шала |
