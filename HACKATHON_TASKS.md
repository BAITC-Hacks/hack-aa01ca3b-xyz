# Innovation track: MVP tasks

## MVP idea

Build a small contractor deadline monitor. A user adds a project document or invoice, confirms its due date, and sees upcoming or overdue work on one dashboard.

## Team tasks

| Owner | Task | Demo result |
|---|---|---|
| Participant 1 — product | Define the user flow and prepare sample project and contractor records. | A clear demo scenario with fictional data. |
| Participant 2 — backend/AI | Store tasks and deadlines; extract document type, contractor, and date from a sample file, with manual confirmation. | A sample document becomes a tracked task. |
| Participant 3 — frontend | Build a dashboard for projects, due dates, statuses, and overdue items. | A working monitoring screen. |
| Participants 2 and 3 | Add a simple upcoming/overdue risk flag and reminder. | The dashboard highlights the next action. |
| Everyone | Run the full flow and prepare a short pitch. | A working end-to-end demo. |

Replace participant numbers with the team members' names before the sprint.
