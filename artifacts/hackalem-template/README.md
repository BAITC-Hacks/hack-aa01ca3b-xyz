# brieflyAI — рабочий шаблон

Откройте index.html через localhost или HTTPS. Рабочий стол позволяет загрузить и прослушать аудио/видео, записать микрофон с паузой и скачиванием, вручную заполнить транскрипт и саммари, вести поручения, сохранять черновик в localStorage и экспортировать DOCX. Для PDF открывается печать браузера — выберите «Сохранить как PDF». Доступ к микрофону требует разрешения браузера.

Сайдбар закрывается кнопкой × и открывается кнопкой ☰. Дополнительные SVG-экраны находятся в разделе «Примеры макета» и используют демонстрационные данные. Автоматическое распознавание, диаризация, извлечение поручений и подключение к Teams/Zoom/Meet в этом статическом шаблоне не выполняются. Реальный frontend и локальный API расположены в корневых frontend/ и app/api/.
