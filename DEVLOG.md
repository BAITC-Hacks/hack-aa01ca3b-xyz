# Журнал разработки (23.09.2026, соревновательная часть 13:00–18:00)

## 13:00–14:00 — выбор задачи и первый прототип
- Выбрали трек 08 «Инновации», разобрали ТЗ кейса и оба примера протоколов из него.
- Решение по архитектуре: всё локально (ТЗ запрещает облачные API), сначала диаризация, потом распознавание, поручения извлекает локальная LLM.
- Первый прототип на Streamlit: загрузка записи → faster-whisper → pyannote → Ollama → DOCX/PDF.

## 14:00–15:00 — экспорт, панель, качество распознавания
- CSV-экспорт поручений, макет панели контроля сроков, кнопка сброса демо-данных.
- Диаризация переведена на sherpa-onnx (pyannote-segmentation-3.0 + 3D-Speaker) без токенов Hugging Face. На синтетической записи найдено 4 голоса из 4.
- Распознавание: реплики на казахском и шала обрабатывает `whisper-turbo-kaz-rus` (дообучена на ISSAI KSC2 + Golos), русские — `whisper-large-v3-turbo`.
- ИИ-агент: участники по обращениям → поручения по 14 правилам → самопроверка → проверка дат. У каждого поручения есть цитата и время.
- Синтетическая тестовая запись ru/kk/шала (голоса macOS Aru и Milena), примеры из ТЗ и эталонные таблицы, `scripts/evaluate.py`.
- Первая проверка на примерах организаторов: найдены 16 поручений из 16, ответственный верный у всех, сроки верны в 9 из 15.

## 15:00–16:00 — точность сроков и воспроизводимость
- Детерминированный пересчёт сроков в даты (`app/services/deadlines.py`): «до пятницы», «за две недели», «к пятнадцатому октября», «жұмаға дейін».
- README переписан под критерии ТЗ: проверка за 5 минут, таблица соответствия, архитектура, ловушки, приватность.
- Проверка скрипта загрузки моделей; устаревшие параметры Streamlit заменены.
- Повторная проверка на примерах организаторов: найдены 16 поручений из 16, сроки верны в 15 из 15 (было 9 из 15).
- Запись совещания с микрофона прямо в интерфейсе (сценарий 1 ТЗ) и кнопка готового примера как страховка на демо.
- Проверка с нуля по README (чистый клон → pip → загрузка моделей → run_demo) прошла на macOS M1 с 8 ГБ.
- Маршрутизация зависит от памяти: при ОЗУ < 12 ГБ работает одна модель kaz-rus, так распознавание быстрее примерно в 9 раз.
- Защита от галлюцинаций: имена, которых нет в транскрипте, отбрасываются. Казахская модель получает язык явно (kk/ru).

## 16:00–17:00 — структура репозитория, имена участников, финальные проверки
- Репозиторий разложен по слоям: `app/core`, `app/services`, `app/main.py`, `data/samples`, `frontend/`. После переезда проверены запуск, модели, шрифты и примеры.
- Имена участников определяются детерминированно по обращениям (имя и отчество → следующий говорящий): в примерах из ТЗ найдены все выступающие участники, 4 из 4. LLM не может дать говорящему имя, которое он сам произносит, обращаясь к другому.
- На машинах с ОЗУ < 12 ГБ распознавание идёт в два прохода: kaz-rus для всех реплик, затем русские реплики уточняет whisper-large-v3-turbo. В памяти одна модель за раз, у русского текста есть пунктуация.
- Флаги в протоколе остаются только проверенные программой: без срока, неверная дата, противоречия.
- Финальная проверка по README со свежего клона с GitHub прошла: pip → загрузка моделей → run_demo.
