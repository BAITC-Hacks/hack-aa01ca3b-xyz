# Передача контекста между ИИ

Обновляйте этот файл, чтобы следующий ИИ или участник команды мог быстро понять состояние проекта и продолжить работу.

## Перед началом работы

1. Прочитайте этот файл и `README.md`.
2. Проверьте `git status` и последние коммиты: другие участники могут работать параллельно.
3. Найдите требования хакатона и поручения в исходных документах. Не считайте их выполненными, пока результат не подтверждён кодом, документом или командой.
4. После изменения добавьте запись в раздел «Журнал изменений»: дата, что сделано, какие файлы затронуты, коммит/пуш и известные ограничения.
5. Не записывайте сюда пароли, токены, приватные ссылки или персональные данные.

## О проекте

Репозиторий хакатона: `BAITC-Hacks/hack-aa01ca3b-xyz`. Есть Streamlit-приложение, FastAPI, React-клиент и Docker Compose для локального контура. Их работа ещё не проверена запуском после последних изменений.

- `app/main.py` — интерфейс Streamlit: загрузка записи, обработка, проверка поручений и экспорт.
- `app/services/` — распознавание, диаризация, анализ, дедлайны, медиа и экспорт.
- `app/core/config.py` — общие пути проекта, данных и моделей.
- `app/api/main.py` — FastAPI: health, обработка записи, экспорт.
- `frontend/src/` — React-интерфейс загрузки, проверки и экспорта результата; `vite.config.js` проксирует API при разработке.
- `Dockerfile`, `docker-compose.yml`, `frontend/Dockerfile`, `frontend/nginx.conf` — контейнерная сборка API, React и локального Ollama.
- `data/samples/` — тестовые записи и эталон; `data/templates/fonts/` — шрифты экспорта.
- `README.md` — установка, запуск, демонстрационный сценарий и ограничения.
- `HACKATHON_TASKS.md` — исходный список задач трека инноваций.
- `CASE_TASK_MAP.md` — распределение командной работы и покрытие требований.

## Как трактовать примеры поручений

Поручения из `data/samples/organizer_examples/` и `data/samples/synthetic_meeting_script.txt` — тестовые данные кейса для настройки инструкций и оценки извлечения LLM, а не для дообучения весов модели. Они не являются задачами, порученными участникам нашей команды, и не означают, что сотрудники в примерах реально выполнили работу. Ожидаемые ответы и даты для оценки находятся в `data/samples/gold.json`; прогресс команды ведётся в `CASE_TASK_MAP.md`.
